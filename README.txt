قالب سایت مؤسسه همسریابی — نسخه بدون پوشه تصاویر
همه فایل‌ها از جمله تصاویر در ریشه ZIP قرار دارند و پوشه images وجود ندارد.
فایل‌ها را همگی مستقیماً در ریشه مخزن GitHub Pages آپلود کنید.
شامل index.html، style.css، script.js، تصاویر JPG و این راهنما.
توجه: تصاویر از تصویر مرجع برش خورده‌اند؛ پیش از انتشار از داشتن مجوز استفاده از تصاویر اطمینان حاصل کنید. آمار و مشخصات و نظرات، نمونه نمایشی هستند.
